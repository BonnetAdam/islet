# Islet brand

**Name**: Islet. A small island: the Dynamic Island, on a Mac.
**Tagline**: The notch, made useful. (FR: L'encoche, enfin utile.)

## Mark

`mark.svg` and the app icon (`icon-1024.png`, generated by `scripts/make-icon.swift`) show the top of a screen
at dawn, a lagoon gradient, with the black island hanging from its edge and a live activity inside it: a cover on
the left, dancing bars on the right. The island uses the app's own outline (concave ears, continuous corners).

## Colour

| Token | Hex | Use |
|---|---|---|
| Night | `#05080A` | The island, the dark panels |
| Glow | `#4FE3C1` | The accent inside the island and on dark surfaces |
| Lagoon | `#0E9F85` | The accent on light surfaces, links, the headline accent |
| Mist | `#EEF3F1` | Page background, light theme |
| Ink | `#0F1B1F` | Text, primary buttons |
| Tide | `#56686D` | Secondary text |
| Icon gradient | `#6AF2D4` → `#1FB095` → `#0C5A5E` → `#072A30` | App icon and mark only |

Semantic colours inside the island follow macOS: green `#33D666` for done and charging, orange `#FF9F0A` for waiting
and timers, red `#FF453A` for denied and low battery.

## Type

- Display: Familjen Grotesk, 600 to 700, tight tracking (-0.02em to -0.045em).
- Text: Onest, 400 to 600.
- Code: JetBrains Mono.
- Inside the app: the system font (SF Pro, SF Pro Rounded for the clock).

## Voice

Short, concrete, calm. Say what happens. No exclamation marks, no em dashes.
