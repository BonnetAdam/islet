How it works

Small parts, each doing one thing well.

Islet is open source, so here is exactly what runs on your Mac and why it stays light.

1

A window shaped like the notch

A borderless panel sits over the camera. Closed, it is exactly the size of the notch, so the menu bar around it keeps every click. Nothing watches your pointer: the window itself notices when you arrive.

2

Drawn by the Mac's compositor

The island's outline is a Core Animation shape morphed with springs. The bars, rings and countdowns beside the camera are animations the system plays by itself, so the app does no work per frame.

3

Content only while it is open

The pages you see when the island opens are SwiftUI views, created as it opens and thrown away as it closes. A closed island holds no view tree at all.

4

Listening instead of polling

Volume, audio devices, the battery, the microphone and the camera all tell Islet when they change. The music comes from a 4 MB helper that reads what macOS already knows is playing.

5

A socket only you can reach

Scripts, Shortcuts and Claude Code talk to Islet through a file in your user folder. No network port, no account, no data leaves the Mac.

6

Read it, change it

Swift, AppKit and SwiftUI, with the rules that open and close the island tested on their own. MIT licensed: fork it, ship it.

For developers

A notch your scripts can talk to.

Islet listens on a local socket that only your user account can reach. The islet command wraps it: one line in any script puts a live activity beside the camera.

  • Progress rings, text, colours and SF Symbols
  • Claude Code hooks installed in one command
  • Allow or deny a tool from the notch, or answer in the terminal as usual
  • Extensions, Shortcuts actions and islet:// links

Questions

      
Does my Mac need a notch?
Islet is made for MacBooks with a notch. On other Macs and external displays it draws its own island at the top of the screen.

      
Is it really free?
Yes. Islet is free and open source under the MIT licence.

      
Which permissions does it ask for?
Each one only when a feature needs it: Accessibility for the volume and brightness keys, Calendars for the agenda, the camera only when you open the mirror.

      
Is it safe with Claude Code?
Islet never signs in to Claude. It listens to the hooks Claude Code itself calls on your Mac, a documented feature, and Allow in the notch is the same as typing yes in the terminal.

      
Can a website push things to my notch?
No. The socket lives in your user folder and only processes running as you can open it. Browsers cannot reach it.
